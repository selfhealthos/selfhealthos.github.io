# Habits

A completion grid over a configurable window (30/60/90 days, or 6 months), with a current streak, best streak, and 7-day/30-day completion rate per habit.

## The streak-counting rule

Current streak counts back from **yesterday** if today hasn't been ticked off yet — not from today. Counting from today would show every habit's streak as broken first thing every morning, before you've had a chance to check anything off, which reads as "you failed" when really you just haven't done today's check-in yet.

## Habit name matching

A habit completion is matched to its habit primarily by a direct link, falling back to a case-insensitive name match if that link is missing (which can happen if a completion arrives before the habit record that explains it, or from an import with inconsistent capitalisation). "Magnesium" and "magnesium" are treated as the same habit for this purpose.
