# Sleep

Each night gets a full architecture breakdown, not just a duration:

- **Hypnogram** — the full stage-by-stage chronology of the night (deep, light, REM, awake), where the data exists. Older or intraday-sparse syncs may only carry session totals without the minute-by-minute chronology — the page says so rather than showing an empty chart as if nothing happened.
- **Architecture** — sleep onset time, REM latency, WASO (wake-after-sleep-onset — deliberately excluding the time spent falling asleep in the first place, which is a different fact: "latency," not fragmentation), wake episode count, and sleep cycle count. Cycles are derived by merging REM periods separated by short gaps, so a brief stir mid-REM doesn't get counted as two cycles.
- **Stage share** — percentage of the night in each stage, shown against typical adult reference ranges.
- **Overnight oxygen** — nadir, minutes under 90%/88% SpO2, and dip detection against a rolling baseline. This is explicitly **not** a clinical apnoea index (an ODI) — a wrist-worn optical sensor averaging over a full minute cannot reliably catch the brief dips that define real apnoea events, and the app doesn't claim otherwise.
- **Heart rate extremes** for the night, and a rule-based, deterministic verdict sentence — for example, distinguishing "short but efficient sleep" (a schedule problem) from "short and inefficient sleep" (a quality problem), two things that look identical if you only look at duration. The verdict is generated by fixed rules, not a model, so the same numbers always produce the same sentence.
- **Baseline comparison** against your own trailing 30 days (once at least 5 nights of history exist — below that, the comparison is left blank rather than shown against too little data to mean anything).

Only main sleep sessions appear on these pages — naps are recorded but excluded from the sleep architecture views, which are built around a single main session per day.

## Bedtime consistency

The trends page's bedtime-consistency figure uses a circular standard deviation, not a naive one — a naive calculation would treat a 11:50pm bedtime and a 12:10am bedtime as 24 hours apart instead of 20 minutes, which is exactly backwards for a metric meant to describe how consistent your schedule is around midnight.
