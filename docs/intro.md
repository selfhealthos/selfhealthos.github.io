# Introduction

**selfhealthos** is a self-hosted, open-source nutrition and fitness tracker. Sleep, activity, heart rate, food, habits, body measurements, lab results — one dashboard, running on hardware you own.

It's built for people who want the depth of a real health dashboard without handing that data to a third party: multi-user, self-serve signup, a Fitbit sync, an interactive REST API, and an MCP endpoint so Claude Code can query your own data directly.
