# selfhealthos.github.io

Documentation site for [selfhealthos](https://github.com/selfhealthos/selfhealthos), a self-hosted, open-source nutrition and fitness tracker. Built with [Docusaurus](https://docusaurus.io/), published to GitHub Pages on every push to `main`.

Live site: https://selfhealthos.github.io

## What's here

- `docs/` — getting started, features, self-hosting guides (left-nav docs)
- `blog/` — the project changelog, one post per release
- `src/pages/` — the marketing/landing page
- `static/` — logo, favicon, and other brand assets

## Local development

```bash
npm install
npm start        # http://localhost:3000, hot reload
npm run build     # production build to build/
```
