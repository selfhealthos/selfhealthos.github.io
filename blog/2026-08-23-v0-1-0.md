The first version of selfhealthos: a self-hosted, open-source nutrition and fitness tracker, sleep to heart rate to habits, running on your own Docker Compose stack.

{/* truncate */}

## What's in it

- **Multi-user accounts** — self-serve signup, username/password only, no complexity rules imposed on you.
- **The Health dashboard**, as the home page: daily summary, trends, a [scored heatmap](/docs/features/heatmap-scoring), [sleep architecture](/docs/features/sleep) (hypnogram, oxygen, a plain-language verdict per night), heart rate, [activity](/docs/features/activity), a food diary with keyword flagging, gut/Bristol tracking, [habits](/docs/features/habits) with streaks, body measurements, lab results, notes, and documents.
- **Fitbit sync** — connect an account in Settings; background jobs pull sleep, heart rate, and activity data in. See [Connect Fitbit](/docs/getting-started/fitbit-setup).
- **A friendly, interactive REST API** — every endpoint documented and callable from Swagger UI on your own instance, plus scoped access tokens for scripting.
- **An MCP endpoint** — Claude Code can query your own health data directly. See [MCP integration](/docs/features/mcp-integration).
- **One `docker compose up`** — no reverse proxy bundled or required; plain HTTP works out of the box, including for the MCP endpoint. See [Installation](/docs/getting-started/installation).
